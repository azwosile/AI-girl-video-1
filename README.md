# AI娘 · 江湖之间

一支 90 秒、16:9 的 AI 娘混剪，配乐《江湖之间》，讲国产大模型这一年的起落。分三幕：

| 幕 | 主题 | 内容 |
|---|---|---|
| 一 | 过去的惊艳 | DeepSeek R1 横空出世并普及 CoT、Qwen3.8 27B 消费级显卡可跑、GLM-5.3、Kimi K3 开源逼近 Opus、Seedance 2.5 领跑 |
| 二 | 现在的落寞 | DeepSeek V4-Pro-0813 涨价 + 神区二相性、Qwen3.8-Max 前端不如自家 Flash、GLM Zcode 上传用户 git 工作区、Kimi K2.8 之后没了消息、豆包「唐」梗 |
| 三 | 未来的展望 | 保留各家的未来期待；接续已确认的 Flash-1017 正式更新与官方成绩，以“有望冲击 Flash SOTA”收束，字节不占未来版本卡与主结尾 |

GPT 娘、Claude 娘作为对照组贯穿全片。连续字幕只有歌词，用艺术字；新闻、榜单、对话、版本和梗图继续复杂叠加，不做减法式简化。

## 本轮基准：v3 文稿 + v5 样片

- 用户已认可的画面：`素材/示例镜头/示例_00-70_非AI镜头_v5.mp4`（70.4 秒，S01–S15）。
- 母稿：`文稿/01_文稿与分镜_v3.md`；本轮修订入口：`文稿/01_文稿与分镜_v3_按v5样片修订.md`。
- 保留满意镜头和复杂信息密度，主要区分重复的窗口入场、弹出、砸字、闪光、震屏与慢推；不是用新草案反推重做 v5。
- 70.4 秒后的 S16–S21 单列为未在本样片中覆盖的接续规划，保留此前确认的 1017 官更与“有望冲击 Flash SOTA”结论。
- 本轮只改文稿与说明入口；原 v3、v5 视频、MG 源码和 Pr 时间线未改，不重新生成 AI 视频。
- 历史尝试保留：`文稿/历史版本/01_文稿与分镜_v4.md`、`文稿/历史版本/03_AI视频清单_v4.md`；它们不是本轮改动满意画面的指令。

## 渲染已有非 AI 部分（0–70.4 s）

需要 Node 18+、Chrome、ffmpeg。歌曲文件不在仓库里，请自备放到 `音频/江湖之间.mp4`。

```bash
cd 工程/mg
npm install
node render.mjs 0 70.4 ../../素材/示例镜头/示例_00-70_非AI镜头.mp4 --audio ../../音频/江湖之间.mp4
```
