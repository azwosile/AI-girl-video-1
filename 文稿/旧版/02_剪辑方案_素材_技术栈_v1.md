## 2. 剪辑方案

### 规格
- 序列：**1920×1080，30fps**（想要更锐利可以做 2560×1440 再导出），音频 48kHz
- 导出：H.264，码率 20–30 Mbps，B 站上传选“高码率”

### 节奏（83 BPM）
- 一拍约 **0.72s**，一句歌词约 **8 拍 / 5.7s**
- **第一幕**：每句歌词一个模型。句首切到“角色立绘 + 标题字”，句中按拍快切 2–3 张证据截图（新闻、榜单）
- **第二幕**：节奏放慢，一句一个镜头，用缓推、慢摇，让“逃不过 / 忘不了 / 躲不了 / 寻不到”自己说话
- **第三幕**：以 ShowMaker 搭桥，之后逐渐加速；最后一句“既然无缘寻一场好眠”放慢，用字节的梗收尾
- **两个关键呼吸点**：43.5s（副歌前黑场 0.3s），66.6s（第二遍副歌前白字“但江湖，还没散场”）

### 调色
| 幕 | 风格 | Pr Lumetri 建议 |
|---|---|---|
| 惊鸿 | 暖金、通透 | 色温 +10，饱和 115，高光偏橙 |
| 相忘 | 冷灰、颗粒 | 饱和 30–40，阴影偏蓝青，加胶片颗粒 |
| 归来 | 冷转暖（日出） | 用调整图层做饱和/色温关键帧，从 70.4s 开始回彩 |

### 字幕样式（对标参考视频）
- 主字幕：宋体 / 楷体类，白色，居中偏下三分之一，关键词用金色
- 副字幕：小一号无衬线字体，70% 不透明度
- 免费字体：**思源宋体 Heavy**（主）、**霞鹜文楷**（副）、阿里巴巴普惠体（数据卡）
- 出字：每句歌词起拍时淡入 + 轻微上浮（6–10 帧），句尾提前 5 帧淡出

### 转场与包装（AE 负责）
1. 片头：打字机出字“2025 年 1 月 20 日”
2. 跑分柱状图动画（镜头 3、4）
3. 水墨 / 墨迹遮罩转场（江湖风，每幕之间用）
4. 43.8s 胶片烧灼 + 黑场
5. ZCode 镜头：假终端界面 + 上传进度条
6. 片尾片名“国模 · 江湖之间”

### Pr 工作流
1. 导入音频 → 导入 `歌词时间轴.srt` 当参考轨（锁定、不导出），按歌词起点打序列标记
2. 导入 `屏幕字幕_v1.srt` → 转成字幕轨，统一套用样式
3. 按分镜把素材拖到对应区间 → 粗剪
4. 需要动画的镜头用 Dynamic Link 送进 AE
5. 调色（三个调整图层对应三幕）→ 加混响 / 音效（心跳、风声、键盘声）→ 导出

## 4. AI 视频（MiniMax H3）

**结论：这台电脑跑不了本地 H3。** 社区教程给出的最低配置是 12GB 显存 + **32GB 内存**（16GB 会爆内存），ComfyUI 版即使量化后总内存占用也在 40GB 级别。你的电脑是 8GB 显存 + 16GB 内存，而且没装 ComfyUI。

可选方案：
- **A（推荐）**：用 MiniMax 开放平台（海螺）的**云端 API**。你给我 API Key，我用 ShunCode 的 `configure_mcp` 接上 MiniMax 官方 MCP，然后直接用立绘做“图生视频”，生成的视频下载到 `素材/AI视频/`
- **B**：你在海螺 AI 网页上手动生成，我只负责写提示词
- **C**：把内存加到 32GB 以上再装 ComfyUI + H3 INT8 量化版。能跑，但很慢，不建议为这一个视频折腾

## 5. 让我操控 Pr / AE

### 方案一：安装 Pr MCP（能实时操作时间线）
- 推荐 **premiere-pro-mcp**（github.com/leancoderkavy/premiere-pro-mcp，MIT，npm 包同名）：支持 Windows + Pr 2020–2026，走本地 CEP 桥接；附带一个 AE MOGRT（字幕模板）连接器
- 安装步骤：`npm install -g premiere-pro-mcp` → `premiere-pro-mcp --install-cep`（会写入 CEP 调试注册表项）→ 重启 Pr → 打开“窗口 > 扩展”里的面板 → 我用 `configure_mcp` 把它接进 ShunCode
- 接好后我可以：建序列、导入素材、按标记放片段、加字幕和转场、导出
- **需要你同意后才装**（会全局安装 npm 包并改注册表）

### 方案二：不装 MCP，我直接生成工程文件（零安装、更稳）
- 生成 **Premiere 可导入的 XML 时间线**：音频、22 个分镜占位（按歌词时间卡好）、标记、字幕全部摆好，你在 Pr 里“文件 > 导入”就能打开
- AE 部分：我写 ExtendScript（.jsx），用 `AfterFX.exe -r` 执行，自动生成片头、柱状图、片尾模板
- 素材到位后，我再用脚本把占位片段替换成真实素材

## 6. 适合这类混剪的技术栈

| 环节 | 推荐 | 说明 |
|---|---|---|
| 主剪辑 | **Premiere Pro** | 卡点、字幕、调色都在这里；你已安装 |
| 包装动画 | **After Effects** | 片头、数据卡、转场；通过 Dynamic Link 和 Pr 互通 |
| 快速替代 | 剪映专业版 | 自动卡点、字幕识别、特效很快；适合先出样片 |
| 节拍 / 歌词时间轴 | Python + numpy、faster-whisper | 本次已用它们做出 83 BPM 和歌词 SRT |
| 素材处理 | ffmpeg | 批量转码、截片段、统一帧率 |
| 网页截图 | Playwright | 新闻、榜单、HF 页面批量 4K 截图，尺寸统一 |
| 时间线生成 | OpenTimelineIO / FCP7 XML | 用代码生成 Pr 能导入的时间线（方案二） |
| 数据动画（可选） | Remotion（React 写视频） | 跑分图、时间轴动画用代码批量出，风格统一 |
| AI 视频 | MiniMax / 海螺 API、Seedance、可灵 | 让立绘动起来；本机跑不了 H3 |
