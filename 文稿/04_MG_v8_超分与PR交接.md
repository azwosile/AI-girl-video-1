## 三、超分：比 Real-ESRGAN 新的方案（2026-10）

| 排名 | 方案 | 适合 | 说明 |
|---|---|---|---|
| 1（最新，先观望） | **FlashVSR+**（2026-10-14 开源，上海 AI Lab / 港中文 / 清华） | 有 Linux + 24 GB 卡时的首选 | 一步扩散 VSR；Hybrid Attention 让 DiT 提速约 2 倍、峰值显存降 45%；4090 上可以不分块直出 4K。**限制**：只支持 Linux + CUDA，输入宽高都要能被 128 整除（864×480 要先补边到 896×512），README 里没有 ComfyUI 节点。目前在这台 Windows 机上要走 WSL，不建议现在就用 |
| 2（推荐现在用） | **FlashVSR v1.1** + ComfyUI 节点 `naxci1/ComfyUI-FlashVSR_Stable` | 本机 ComfyUI 直接用 | 选 tiny-long + tiling、chunk 约 20、fp16。速度约为 SeedVR2-3B 的 12 倍；至少要 21 帧输入（我们的片段 58–141 帧，够用） |
| 3（画质最强、最慢） | **SeedVR2 3B GGUF Q4_K_M**（Apache 2.0，ComfyUI 官方有教程） | 只超 4–5 个关键镜头 | 对 AI 生成画面效果最好；blocks_to_swap 拉满、开 VAE tiling、batch 用 4n+1 |
| 兜底 | 逐帧 ESRGAN 系 / AnimeJaNai V3 | 动漫风、要稳 | 没有时序一致性，可能闪烁 |
| 补帧 | RIFE | 24 → 30 / 60 fps | 可选 |

**建议流程**：864×480 → FlashVSR v1.1 ×2（1728×960）→ Lanczos 到 1920×1080 → 导出 JPG 序列，按同名覆盖 `assets/clips/<key>/` → 重渲 MG。

## 四、PR / AE + MCP 交接

- 远端 MCP 已经挂上 **Premiere Pro 扩展工具**（`ext__premiere_pro__*`：读序列、检查时间线、预检、导出与校验等）。进入 PR 阶段时，先跑 `ping` / `verify_premiere_connection`。
