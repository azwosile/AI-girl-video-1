## FlashVSR 本机修补（只改插件目录，没往 aki 的 Python 里装任何包）
- `src/models/utils.py`：Windows 上读 >2 GB 的 safetensors 改走逐块 read（`st_fallback.py`）。原因：safetensors 0.7 + torch 2.13 用 mmap 读 5.7 GB 主模型时 access violation。
- `src/models/model_manager.py`：safetensors 直接按目标精度（bf16）读入，避免 fp32 和 bf16 两份同时占内存。
- 原文件都留了 `.orig`。
- 本机 16 GB 内存，其中 `simprint.exe` 占了约 7 GB，跑超分前最好先把它关掉。

## FlashVSR 显存常驻跑法（8 GB 显卡实测通过）
```
cd "E:/AI/FlashVSR v1.1 视频超分/ComfyUI-FlashVSR_Stable"
PYTHONIOENCODING=utf-8 PYTHONUTF8=1 /e/AI/ComfyUI-aki-v3.2/python/python.exe cli_main.py \
  --input in.mp4 --output out.mp4 --scale 2 --mode tiny-long --vae_model LightVAE_W2.1 \
  --tiled_vae --tiled_dit --frame_chunk_size 0 --no_keep_models_on_cpu --no_force_offload
```
- S18：73 帧 864×480 → 1728×960，用时 11 分钟（0.11 fps）。显存峰值 6.6 / 8.0 GB，Python 进程常驻内存约 3 GB，帧号与原片逐帧对齐。
- 共享显存（Windows「共享 GPU 内存」）其实就是系统内存，走 PCIe 访问，比显存慢一个数量级，而且和程序抢同一块内存，在内存吃紧时帮不上忙。现在常驻显存已经够用，不需要靠它。
