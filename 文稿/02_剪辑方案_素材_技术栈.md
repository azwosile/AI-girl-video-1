## 2. 剪辑方案

### 规格
- 序列：**1920×1080，30fps**（想要更锐利可以做 2560×1440 再导出），音频 48kHz
- 导出：H.264，码率 20–30 Mbps，B 站上传选“高码率”

### 节奏（83 BPM）
- 一拍约 **0.72s**，一句歌词约 **8 拍 / 5.7s**
- **第一幕**：每句歌词一个模型。句首切到“角色立绘 + 标题字”，句中按拍快切 2–3 张证据截图（新闻、榜单）
- **第二幕**：节奏放慢，一句一个镜头；每镜和第一幕同一家做“镜像对照”（同构图，彩色变灰）
- **第三幕**：未来名单承接期待，10.17 Flash-1017 正式更新与官方跑分推动结尾；最后落在“Flash-1017 正式更新，有望冲击 Flash SOTA”，不再用字节长对白收尾
- **呼吸与密度**：43.5s 附近保留短黑场；66.9s 四卡翻起后让 10.17 新消息挤入。新闻、数据、角色、歌词与滚动信息继续复杂叠加

### 调色
| 幕 | 风格 | Pr Lumetri 建议 |
|---|---|---|
| 惊鸿 | 暖金、通透 | 色温 +10，饱和 115，高光偏橙 |
| 相忘 | 冷灰、颗粒 | 饱和 30–40，阴影偏蓝青，加胶片颗粒 |
| 归来 | 冷转暖（日出） | 用调整图层做饱和/色温关键帧，从 70.4s 开始回彩 |

### 字幕样式：只有歌词，中文艺术字
- 屏幕上唯一的字幕是歌词（`屏幕字幕_v3_歌词.srt`），原来的标题 / 副标题全部删掉
- 字体：**纸忙行书 Zhi Mang Xing**（OFL，可商用，已放在 `素材/字体/`，双击安装后 Pr / AE 都能用）；备选马善政楷书（更易读）
- Windows 自带的华文行楷、方正舒体等商用要另外授权，B 站投稿有收益的话不建议用
- 样式：象牙白 → 金色渐变、墨色投影、淡金色外发光，放在画面高度 80% 处；歌词下方加一条很淡的墨色带
- 动画：逐字出现（模糊 → 清晰、略微缩小落定、轻微上浮），每个字对准演唱的那个字；句尾提前 0.5s 淡出
- 做法二选一：① AE 里用逐字动画预设做成 MOGRT，在 Pr 里套用；② 我用脚本把 20 句歌词直接渲染成**带透明通道的歌词层**（ProRes 4444），在 Pr 里放到最上面一轨就行 —— 示例镜头里的歌词就是这样做的

### 转场与包装（AE 负责）
1. 数据卡：跑分 / 价格柱状图（镜头 2、3、5，示例镜头已有样式）
2. 角色卡翻牌（镜头 15：四个版本号逐个亮起）
3. 水墨 / 墨迹遮罩转场（江湖风，每幕之间用）
4. 43.8s 胶片烧灼 + 黑场
5. ZCode 镜头：事件截图 + 官方回应 + 标“示意”的终端动画，不放真实用户信息
6. 结尾不做片名卡：镜头 21 跟着歌曲尾音直接淡出到黑

### Pr 工作流
1. 导入音频 → 导入 `歌词时间轴.srt` 当参考轨（锁定、不导出），按歌词起点打序列标记
2. 放歌词艺术字（MOGRT 或透明歌词层），对照 `屏幕字幕_v3_歌词.srt` 的时间
3. 按 `01_文稿与分镜_v3_按v5样片修订.md` 的 21 个镜头（S01–S15 已有 v5 样片，S16–S21 为接续规划）把素材拖到对应区间 → 粗剪
4. 需要动画的镜头用 Dynamic Link 送进 AE
5. 调色（三个调整图层对应三幕）→ 加混响 / 音效（心跳、风声、键盘声）→ 导出

## 4. AI 视频（H3 / updream / Seedance）

- 本轮只试生成新 A09：DeepSeek 娘重新抬眼的微动底片。A1 / A4 是后续可选，不自动批量排队；其他原 A 编号改用现有素材与复杂 MG
- 提示词、替代清单与执行方式见 `03_AI视频清单_v4.md`。沿用实际工作流的 10 步设置，试片约 3 秒 / 73 帧 / 864×480 / 24fps，不在本轮自动启用未接入该图的 Turbo LoRA
- 通过本机 ComfyUI API（127.0.0.1:8188）只提交一条任务，保存实际 prompt_id 并查询同一任务；非空文件与 ffprobe 验证后才报告生成成功

### 放大（8GB 显存）
- **首选 SeedVR2 3B GGUF**（ComfyUI-SeedVR2_VideoUpscaler，Q4_K_M 或 Q8_0，blocks_to_swap 32，VAE tiled）：480P → 1080P，10 秒约 8 分钟
- 赶时间用 **FlashVSR**；保底用 **Real-ESRGAN animevideov3**（动漫风、最快）；可选 **RIFE** 插帧到 48 / 60fps
- 详细参数见 `03_AI视频清单_v3.md` 末尾

## 5. 让我操控 Pr / AE

### 方案一：安装 Pr MCP（能实时操作时间线）
- 推荐 **premiere-pro-mcp**（github.com/leancoderkavy/premiere-pro-mcp，MIT，npm 包同名）：支持 Windows + Pr 2020–2026，走本地 CEP 桥接；附带一个 AE MOGRT（字幕模板）连接器
- 安装步骤：`npm install -g premiere-pro-mcp` → `premiere-pro-mcp --install-cep`（会写入 CEP 调试注册表项）→ 重启 Pr → 打开“窗口 > 扩展”里的面板 → 我用 `configure_mcp` 把它接进 ShunCode
- 接好后我可以：建序列、导入素材、按标记放片段、加字幕和转场、导出
- **需要你同意后才装**（会全局安装 npm 包并改注册表）

### 方案二：不装 MCP，我直接生成工程文件（零安装、更稳）
- 生成 **Premiere 可导入的 XML 时间线**：音频、22 个分镜占位（按歌词时间卡好）、标记、字幕全部摆好，你在 Pr 里“文件 > 导入”就能打开
- AE 部分：我写 ExtendScript（.jsx），用 `AfterFX.exe -r` 执行，自动生成片头、柱状图、片尾模板
- 素材到位后，我再用脚本把占位片段替换成真实素材

## 6. 适合这类混剪的技术栈

| 环节 | 推荐 | 说明 |
|---|---|---|
| 主剪辑 | **Premiere Pro** | 卡点、字幕、调色都在这里；你已安装 |
| 包装动画 | **After Effects** | 片头、数据卡、转场；通过 Dynamic Link 和 Pr 互通 |
| 快速替代 | 剪映专业版 | 自动卡点、字幕识别、特效很快；适合先出样片 |
| 节拍 / 歌词时间轴 | Python + numpy、faster-whisper | 本次已用它们做出 83 BPM 和歌词 SRT |
| 素材处理 | ffmpeg | 批量转码、截片段、统一帧率 |
| 网页截图 | Playwright | 新闻、榜单、HF 页面批量 4K 截图，尺寸统一 |
| 时间线生成 | OpenTimelineIO / FCP7 XML | 用代码生成 Pr 能导入的时间线（方案二） |
| 数据动画（可选） | Remotion（React 写视频） | 跑分图、时间轴动画用代码批量出，风格统一 |
| AI 视频 | 本机 MiniMax H3（ComfyUI）、updream 工作台、Seedance | 让立绘动起来；H3 出 480P |
| AI 放大 | SeedVR2 3B GGUF / FlashVSR / Real-ESRGAN、RIFE | 8GB 显存可跑，480P → 1080P |
| 程序化包装 | Python + Pillow + OpenCV + ffmpeg | 示例镜头、歌词透明层、数据卡都可以脚本批量出 |
