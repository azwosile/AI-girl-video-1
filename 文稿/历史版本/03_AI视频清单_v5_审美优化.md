## 二、v4 出片审美问题（逐帧看过）

对照图：`AI镜头_审美优化/A09_审美优化_对比.jpg` 第一行。

1. **背景和 MG 段语言割裂**：v4 是纯黑房间加一块剪贴画式的显示器图标，而 S16 的 MG 段是墨蓝极光、玻璃卡和金色歌词。两者一接，观众会感觉跳进了另一支片子。
2. **画面里有个“假 UI”**：显示器上是一些无字横条。后期 1017 玻璃卡叠上去以后，就会出现两个屏幕抢主体；不叠的话又显得空。
3. **抠图瑕疵被 H3 放大**：`02_沮丧_透明.png` 的发丝之间有不透明白块，v4 首帧原样带进去了。生成后白块跟着头发一起动，480p 下很显眼。
4. **光影没交代**：显示器从暗到亮是线性变化，读起来像“屏幕开机”，而不是“她被什么照亮”；人物身上也没有任何左侧来光。
5. **情绪落点不可控**：I2VA 只锁住首帧，结尾的表情和视线方向全靠运气。v4 结尾的视线大致朝前，没有看向左边的卡片。
6. **和 v7 现状冲突**：v7 的 S16 用的是全身开心立绘，v4 却是到大腿的沮丧半身。直接替换会让同一个镜头里出现两种情绪起点。
7. **提示词格式小错**：`prompt_A09_Flash1017_v4.txt` 第一行（`...is fully referenced.`）后面紧跟着 `integrated_multimodal_description:`，**缺了 H3 规定的空行**，文件里还混了 `\r\n`。

## 三、v5 设计：AI 只做“底片”，MG 叠在上面

**核心思路**：AI 片段不再是一个独立镜头，而是 S16 的**底层**。左半边留出与 MG 同色的墨蓝空气，1017 玻璃卡、放大镜、歌词、滚动条照常由 MG 叠在上面，人物从“静态立绘”升级为“会呼吸的半身”。

| 项 | v4 | v5 |
|---|---|---|
| 模式 | I2VA | **FL2VA**（首帧沮丧，尾帧带希望），落点可控 |
| 背景 | 黑房间 + 显示器 | 与 v7 同色板的墨蓝极光虚焦，左侧略亮，给玻璃卡留位，**不画任何屏幕** |
| 构图 | 到大腿，人物居中偏右 | 头到胯的中景，人物在右三分之一，左侧 55% 留白 |
| 光 | 平光 + 屏幕变亮 | 左侧屏外钴蓝主光 + 右侧蓝白轮廓光 + 左下极弱的金色反光（呼应金色歌词） |
| 动作 | 抬眼、眨眼、微笑 | 0–1.1 s 静止含泪，只有发梢像在水中一样缓慢漂动（呼应鲸鱼设定）→ 约 1.2 s 左侧来光变亮，一道金光扫过脸颊 → 1.2–1.9 s 抬下巴、**视线转向左边的卡片**、鲸鳍耳轻轻竖起 → 1.9 s 起闭嘴浅笑，眨一次眼，保持到结尾 |
| 抠图 | 有白块 | 已修复（发丝间露出背景） |

**和音乐对位（成片时间）**：静止段压在“忘不了”上，抬眼落在“惊鸿”（约 72.0–72.4 s），正好和放大镜停在 77.0 同时出现，形成“她看见了新成绩”的因果关系。具体帧位留到试剪时再按原曲微调。

**叠层预演**：`S16_合成预演_v5尾帧.jpg`。这张图是把 v7 的卡片、歌词、滚动条直接贴到 v5 尾帧上做的，没有经过真实渲染。卡片右缘会压住一点向左飘的头发。正式合成时，建议把卡片整体左移约 60 px 或缩到 0.94，或者保留遮挡，让玻璃折射头发，这本身也好看。

## 五、通用“底片法”（A1 / A4 以后若启用）

1. 先从 MG 段取色，做一张无 UI、无人物的背景板，要求和 MG 同色、虚焦、给信息卡留出位置。
2. 把原立绘差分合成上去，再用生图模型统一打光，同时修掉抠图白块。
3. 尾帧由首帧推出，只改变头部、眼神、表情和光，然后走 FL2VA。
4. 提示词里禁止出现屏幕、文字和新道具，所有信息都由 MG 后期叠加。
