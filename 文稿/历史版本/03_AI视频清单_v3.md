## 放大到 1080P（8GB 显存可跑）

| 方案 | 用途 | 8GB 设置 | 速度（参考） |
|---|---|---|---|
| **SeedVR2 3B（首选）** | 480P → 1080P，细节和时间一致性最好 | ComfyUI Manager 搜索 `ComfyUI-SeedVR2_VideoUpscaler`；模型选 `seedvr2_ema_3b-Q4_K_M.gguf`（或 Q8_0）；blocks_to_swap = 32；勾选 swap_io_components；VAE 编码 / 解码都开 tiled；batch_size 用 4n+1（1 或 5）；resolution 填 1080 | 10 秒 24fps 约 8 分钟（RTX 3060 8GB 实测数据，5070 Laptop 相近或更快） |

| Real-ESRGAN animevideov3（保底） | 动漫风格、最快 | 逐帧放大，偶尔闪烁 | 很快 |
| RIFE（可选） | 24fps → 48 / 60fps，让动作更顺 | 放大之后再插帧 | 快 |

```bash
python inference_cli.py A9_480p.mp4 --dit_model seedvr2_ema_3b-Q8_0.gguf --resolution 1080 \
  --blocks_to_swap 32 --swap_io_components --dit_offload_device cpu --vae_offload_device cpu
```

建议流程：H3 出 480P → SeedVR2 放大到 1080P → （可选）RIFE 插帧 → ffmpeg 统一转成 30fps 再进 Pr。
