## 5. 执行与验收

所有终端命令在 Bash 中运行。客户端访问的是用户这台 Windows 机器上的 `http://127.0.0.1:8188`，不是聊天沙箱的 localhost。

```bash
# 在项目根目录中；先生成首帧
python -X utf8 '工程/comfy_mcp/prepare_A09_v4.py'
# ComfyUI 在线后，只提交一次
python -X utf8 '工程/comfy_mcp/run_A09_v4.py' submit
# 有界等待；仍在运行就保留同一 prompt_id，不再次 submit
python -X utf8 '工程/comfy_mcp/run_A09_v4.py' status --wait 60
# 确认该任务成功后取回输出并用 ffprobe 验证
python -X utf8 '工程/comfy_mcp/run_A09_v4.py' fetch
```

- 首帧、执行脚本与提示词是准备物；队列返回 prompt_id 仅表示接单，不表示视频成功。
- 只有任务完成、文件非空且 ffprobe 读到有效视频流，才报告“已生成”。
- 抽查脸、鲸鳍耳、领口、发色是否稳定；视线变化是否自然；是否出现说话、突兀挥手或新道具。
- 先判断这段反应能否服务主题，再决定是否做放大、插帧或正式合成；本轮不自动安装新放大器或批量开跑。
- 如果服务未启动，先启动已安装的 ComfyUI；不更新依赖、不关闭其他应用、不清空他人的队列。
